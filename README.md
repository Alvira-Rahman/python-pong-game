# Python Pong Game

A simple two-player Pong game written in Python with the built-in `turtle` graphics module.

This beginner project practices using variables, functions, keyboard events, loops, conditionals, and basic ball-and-paddle collision checks.

## Requirements

- Python 3
- A desktop environment that can open a graphics window
- No third-party Python packages

## Run the game

Open a terminal in this folder and run the command for your system.

**Windows**

```powershell
py pong.py
```

**macOS or Linux**

```bash
python3 pong.py
```

## Controls

| Player | Move up | Move down |
| --- | --- | --- |
| Player A (left paddle) | `W` | `S` |
| Player B (right paddle) | `↑` | `↓` |

The score is shown at the top of the game window.
